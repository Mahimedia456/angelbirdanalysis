# AngelBird Web Reporting Corrections 02

Web-only cumulative patch. Mobile, backend, database, auth, and Sheet sync are not modified.

Changes:
- Removed Ticket Procedure chart.
- Removed Procedure Summary from ticket analytics tables.
- Removed Procedure Wise tab and Procedure column from ticket data tables/exports.
- Ticket tables now show Ticket # first and Date immediately after it.
- Satisfaction rating was removed from the global filter form.
- Satisfaction data table now has its own selector in this order: Good, Bad, All; Good is selected by default.
- Satisfaction table column order remains Ticket ID, Date, Comment, Rating, AI Summary.
- Removed Month-wise RMA chart.
- Previous web refinements remain preserved (All chart limit default, TSE hidden, NA->UAE, Product 2 hidden, Region horizontal bar).
